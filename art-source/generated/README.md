# Raw image-to-3D output

Drop Hunyuan3D (or other generator) exports here as `<catalogKey>.glb`, for example `sofa.glb`,
`floralArmchair.glb`. Keys are listed in docs/PROP_BRIEFS.md. These raw meshes are ignored by git;
the cleaned, game-ready versions go to public/models/<key>.glb after the Blender clean-up described
in docs/PROP_BRIEFS.md.
