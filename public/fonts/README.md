# Bundled fonts

These fonts are licensed under the SIL Open Font License 1.1 and may be bundled and distributed with the game. Licence texts are alongside.

| File | Family | Role | Source |
| --- | --- | --- | --- |
| fredoka-semibold-latin.woff2 | Fredoka (600, Latin subset) | Rounded Little Nest wordmark | [Google Fonts](https://fonts.google.com/specimen/Fredoka) / The Fredoka Project Authors |
| gelasio-latin.woff2 | Gelasio (variable, 400–700, Latin subset) | Serif headings; metric-compatible with Georgia | Google Fonts / SorkinType |
| source-sans-3-latin.woff2 | Source Sans 3 (variable, 200–900, Latin subset) | Body and controls when Segoe UI is unavailable | Google Fonts / Adobe |

The wordmark uses bundled Fredoka on every platform. Segoe UI and Georgia stay first for body text and other headings; Source Sans 3 and Gelasio supply their fallbacks. All font files are served locally by the game.
