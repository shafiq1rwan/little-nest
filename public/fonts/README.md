# Bundled fonts

Both fonts are licensed under the SIL Open Font License 1.1 and may be bundled and distributed with the game. Licence texts are alongside.

| File | Family | Role | Source |
| --- | --- | --- | --- |
| gelasio-latin.woff2 | Gelasio (variable, 400–700, Latin subset) | Serif headings; metric-compatible with Georgia | Google Fonts / SorkinType |
| source-sans-3-latin.woff2 | Source Sans 3 (variable, 200–900, Latin subset) | Body and controls when Segoe UI is unavailable | Google Fonts / Adobe |

Segoe UI and Georgia stay first in the font stacks, so Windows renders exactly as before. Other operating systems fall back to these files instead of an arbitrary system font.
